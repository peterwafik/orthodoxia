# ADR 0004 — Project licenses

**Status:** Accepted, 2026-10-11

- **Code:** MIT (`LICENSE`), the same as the vendored upstream explorer.
- **Original written content** (articles, explanations, editorial relationships): CC BY-SA 4.0
  (`LICENSE-CONTENT.md`). Reuse is allowed, and derivatives must stay open.
- **Third-party data and texts** keep their own licenses. Each one is recorded in
  `content/sources/*.yaml` and shown on `/sources/`. OpenBible.info data (CC BY 4.0) stays under
  its own license and is not relicensed as CC BY-SA.
- Any contribution must be compatible with these licenses (see `CONTRIBUTING.md`).
